# git2_bridge

Internal Flutter FFI plugin (path dependency, not published) exposing
`../../native/include/git_bridge.h` to Dart.

- `lib/git2_bridge.dart` — public API: `Git2Bridge.{clone,pull,push,stage,
  unstage,commit,getStatus,getFileTree,isRepository,getHeadInfo,
  getUnpushedCount}`. Every call runs on a background `Isolate.run`;
  clone/pull/push additionally accept an `onProgress` callback delivered via
  `NativeCallable.listener` across the isolate boundary in real time.
- `lib/src/git2_bridge_bindings_generated.dart` — generated by ffigen, do
  not hand-edit. Regenerate after changing `../../native/include/git_bridge.h`:
  ```sh
  dart run ffigen --config ffigen.yaml
  ```
- `android/`, `ios/` — platform build wiring; see the top-level README's
  "Android" / "iOS" setup sections.
- `test/manual_ffi_smoke.dart` — run via `../../scripts/dart_ffi_smoke_test.sh`,
  not `flutter test` (it needs a compiled native lib on `LD_LIBRARY_PATH`).
