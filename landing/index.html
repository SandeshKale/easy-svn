What it does

The core Git workflow, reduced to what fits on a phone screen.

Clone, pull & push

Over HTTPS with a real progress bar — fast-forward pulls, shallow clones by default.

Stage & commit

Split staged/unstaged view backed by libgit2's real index — not a shell wrapper.

Offline file browser

Browse a repo's tree with zero network access — everything reads from local disk.

GitHub sign-in

OAuth2 with PKCE, straight to the system browser — token stored in secure hardware-backed storage.

Native git engine

libgit2 compiled from source and called directly via dart:ffi — no subprocess, no shell-out.

Real-time progress

Clone/pull/push stream live progress across isolates — the UI never freezes mid-operation.
